# Profile Cohesion Refinement

## Goal

The Master Career Profile should feel like the user's evolving professional identity, not hidden backend data.

## Current Refinements

- Profile copy now explains how saved evidence powers resumes, pathways, and interviews.
- The profile page reinforces that plain evidence can be translated into recruiter-readable functions.
- Career discovery and first-resume answers continue enriching the profile when users are signed in.

## Cohesion Principles

- The profile is the source of truth.
- Generated resumes are tailored views.
- Pathways compare profile evidence to role expectations.
- Interview prep should increasingly practice the proof recruiters will ask for.
- Opportunity notes should capture what happens after the user enters the hiring process.

## Deferred

- Visual timeline of profile growth.
- User-confirmed inferred transferable skill tags.
- Profile-to-output provenance display.
- Profile completeness guidance.
