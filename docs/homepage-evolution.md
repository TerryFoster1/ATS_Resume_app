# Homepage Evolution

## Goal

The homepage should keep evolving from a resume utility into a premium career operating system narrative.

## Positioning Direction

Career Ladder is:

- a lifelong career platform
- a recruiter-aware career intelligence system
- a professional identity platform
- a realistic career navigation system

## Storytelling Priorities

- Show career progression over time.
- Show transferable skill translation.
- Show how ordinary experience becomes recruiter-readable evidence.
- Explain how the Master Career Profile powers outputs.
- Connect discovery, pathways, resumes, interviews, tracking, and offers into one career trajectory.

## Current Implementation Notes

The current app already has landing architecture for discovery, transitions, pathways, resume strategy, interviews, mock interviews, the master profile, and application tracking. This sprint focused on product-surface intelligence rather than another full visual redesign.

## Deferred

- More cinematic homepage progression visuals.
- Dedicated public offer-comparison page.
- More career-transition examples.
- Landing-page variants for student, laid-off, and career-changer audiences.
